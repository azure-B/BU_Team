# 수업 추가 모달을 개설 강의 검색으로 전환

- 일시: 2026-10-17
- 영역: Front

## 변경 요약
- 수업 직접 입력을 전공/영역·요일/시간·구분·검색어 필터와 개설 강의 선택 목록으로 교체했습니다. 검색어는 과목명·교수명·학수번호에 적용합니다.
- 강의의 모든 요일과 실제 시작·종료 시간, 강의실, 교수명을 함께 저장합니다. 중복·시간 충돌을 차단하고 여러 시간으로 구성된 강의는 한 번에 삭제합니다.
- 주말 수업이 등록되면 주간 시간표에 토·일요일을 함께 표시합니다. 모바일에서는 필터를 두 열로 배치합니다.
- 전공/영역 선택지는 `전공 - 컴퓨터공학부`처럼 학부 단위로 표시합니다. 컴퓨터공학부·첨단 아이티 학부·경상학부는 강의 데이터가 없는 로딩·조회 실패 상태에서만 임시 제공하며, 정상 조회 후에는 빈 결과를 포함해 실제 DB의 학부와 영역으로 교체합니다. 학부 선택 시 소속 세부 전공을 함께 검색합니다.
- 로딩·빈 결과·조회 실패·재시도·추가 완료 상태를 표시합니다. 시간 정보가 불완전한 강의는 부분 등록하지 않습니다.

## 사용 API
- GET /api/v1/courses — limit·offset으로 개설 강의 전체 조회 (/api/courses 별칭 지원)
- 배포: Netlify 빌드 환경에서 VITE_API_URL을 Render API 주소로 설정하고, Vite가 저장소 루트 `.env`를 읽도록 구성했습니다. 환경변수가 없을 때의 로컬 기본 주소는 Vite 프록시와 같은 `localhost:5000/api`입니다.

## 확인
- 일정 및 강의 검색 관련 테스트 18건 통과.
- Front 프로덕션 빌드 통과. Netlify API URL을 포함한 `Front/publish/` 산출물을 갱신했습니다.
- 현재 .env의 Supabase 호스트가 DNS 조회에 실패하여 실제 DB 데이터 형식과 API 연동은 확인하지 못했습니다. meetings의 day·startTime/endTime 또는 day·start/end, 단일 수업의 day·startTime/endTime 형식을 처리하며, 실제 강의 예시 확인이 필요합니다.
- 브라우저 도구에 사용 가능한 브라우저가 없어 실제 화면 조작 확인은 수행하지 못했습니다.
