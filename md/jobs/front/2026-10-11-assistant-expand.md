## 후속 수정: 가운데 대화 접힘 모션 및 마지막 크기 기억

- 접기 시작 시 `display: none`으로 대화 영역을 즉시 제거하던 처리를 없앴다. 대화 영역은 flex 공간을 유지한 채 표면 높이와 함께 줄어들며, 입력창·추천 질문은 하단에 고정된다. 접힌 대화는 접근성 트리와 포커스 대상에서 제외한다.
- 꺼짐 여부와 접힘/확장 선호 상태를 분리했다. X·바깥 터치·Escape로 닫아도 마지막 크기를 보존하며 다시 열 때 복원한다.
- `AssistantPreferencesProvider`를 앱에 두어 라우트 전환에서도 크기를 기억한다. 영구 저장소를 사용하지 않아 새 앱 실행/페이지 새로고침 시 기본 접힘으로 초기화한다.
- 변경 파일: `Front/src/components/layout/Footer/{Footer.jsx,Footer.css,AssistantPreferences.jsx}`, `Front/src/App.jsx`, `Front/publish/index.html`, `Front/publish/assets/`, `md/folder.md`, 본 작업 기록.
- 사용 API: 없음.
- 검증: 프로덕션 빌드 성공(기존 500kB 경고 유지). 320·390·1440px에서 접힘 과정의 프레임별 모달 하단·입력창·추천 질문 위치 변화가 2px 이내이며 대화 영역은 점진적으로 줄어드는지 확인했다. X·바깥 터치·Escape 후 상태 복원, 접힘 상태 복원, 페이지 이동 시 상태 유지, 새로고침 시 기본값 복원 검증. 런타임 오류 없음.

## 후속 변경: 손잡이와 고정 높이로 세 상태 관리

- 사용자 수정 요구에 따라 `off`(꺼짐), `collapsed`(접힘), `expanded`(확장)를 명시적으로 관리한다. 열기·다시 열기는 항상 접힘이며 대화 내역은 유지한다.
- 상단 손잡이를 접근 가능한 버튼으로 변경했다. 접기·펼치기 라벨, `aria-expanded`, 키보드 포커스 표시와 80×24px 클릭 영역을 제공한다.
- 입력·추천 칩 선택만으로 확장하지 않는다. 손잡이 클릭으로 접힘/확장을 전환하고 메시지 전송으로 확장한다.
- 확장 높이는 600px로 고정하며 메시지 수와 무관하다. 대화 영역은 남은 공간을 채우고 스크롤한다. 모달 애니메이션 중에도 콘텐츠가 표면 높이에 맞춰 배치된다.
- 모바일 키보드에 대응해 `visualViewport.height`, `offsetTop`, resize/scroll 이벤트로 실제 보이는 화면 안에 위치와 높이를 조정한다. 가용 높이가 600px보다 작으면 상단·하단 여백을 제외한 높이로 제한한다. 키보드가 사라지면 원래 높이로 복원한다.
- 최초 열기 시 입력창 대신 손잡이에 포커스를 두어 키보드가 자동으로 나타나는 것을 피한다. 터치 기기의 입력 글꼴은 16px로 설정하여 iOS의 입력 포커스 확대를 방지한다.
- 변경 파일·사용 API는 아래와 동일하다. 새 백엔드 연동 없음.
- 검증: 빌드 성공. Chrome/Playwright 320·390·1440px에서 세 상태, 타이핑 시 접힘 유지, 손잡이 전환, 전송 시 확장, 13개 메시지에도 600px 높이 유지, 대화 스크롤, 닫기·재열기 시 접힘 및 내역 보존 확인. visualViewport 높이 390px·상단 오프셋 50px를 모의하여 모달·입력창이 가시 영역 안에 유지되고 복원되는지 확인했다. 실제 모바일 시스템 키보드는 직접 검증하지 않았다. 런타임 오류 없음. 모바일 스크린샷 검토 완료.

## 변경 요약

- 최초 호출에는 헤더·입력창·추천 질문만 보이는 컴팩트 모드를 유지한다.
- `isExpanded`는 입력 내용 또는 대화 내역 유무에서 계산한다. 입력을 시작하거나 추천 칩을 선택하면 확장되고, 메시지가 없는 상태에서 입력을 지우면 컴팩트 모드로 돌아간다.
- 전송한 질문을 대화 내역에 추가하고 입력창을 비운다. 기존 650ms 후 자동 닫기 동작을 제거했다. AI 답변 API는 연결하지 않는다.
- 콘텐츠 높이를 측정하여 기존 버튼→모달 스프링 모션으로 높이와 상단 위치를 함께 변경한다. 하단 위치는 고정하며 텍스트를 확대하지 않는다.
- 화면 높이와 모바일 visualViewport에 맞춰 최대 높이를 제한하고 대화 영역만 스크롤한다. 새 메시지에는 최신 대화로 이동한다. Escape·포커스 제한·reduced-motion 동작을 유지한다.
