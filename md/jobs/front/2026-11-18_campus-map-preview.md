# 캠퍼스 지도·길찾기 프론트 미리보기

## 현재 최종 구현 상태

- 운영 `/campus`도 지도 화면에 연결하도록 수정했다. 개발 모드 제한을 제거하고 하단 메뉴를 `/campus`로 통일했다. 기존 `/campus/map-preview`는 `/campus`로 리다이렉트한다. 아래 개발 전용 관련 내용은 이전 단계 기록이다.

- 기존 예시 SVG, 고정 건물 배치, 7분/350m 예시를 제거하고 `KakaoCampusMap`·`campusMapApi`·`loadKakaoMap`을 화면에 연결했다. 아래 이전 작업 내역의 예시 관련 내용은 이전 단계 기록이다.
- 건물 목록은 기존 `VITE_API_URL`의 `/campus/buildings`에서 조회하고 DB의 `x=위도`, `y=경도`를 변환한다. 현재 위치는 브라우저 Geolocation으로 조회하며 권한 거부·미지원·시간 초과를 안내한다.
- 출발·도착 직접 지정/확정/취소, 건물 선택, 교환, 초기화, 카카오 마커/Polyline/범위 맞춤/확대·축소/리사이즈 로직 구현. 지도 준비 전 직접 지정은 차단한다.
- 요청 중 초기화·위치 변경 시 이전 요청을 취소하고 늦게 도착한 경로·GPS 결과를 무시한다. 거리·시간·도착 예정 시각은 실제 API 응답으로만 표시한다.
- 개발 환경 지도 설정·경로 요청: `/campus-api` → 로컬 백엔드 5180. 운영 `/campus`는 기존 API 서버 설정을 사용한다.
- 추가 변경 파일: `Front/src/api/campusMapApi.js`, `Front/src/utils/loadKakaoMap.js`, `Front/src/components/common/KakaoCampusMap.jsx`, `Front/vite.config.js`.
- 검증: 개발 전용 페이지를 포함한 메모리 빌드 통과. 실제 지도/경로 성공과 GPS 기기 검증은 키·도메인·권한 준비 후 필요하다. 테스트용 SDK나 고정 성공 응답을 실제 화면에 넣지 않았다.
- 미완료: 실제 키·도보 제휴 승인, Render 설정 및 호출 로그 확인, 배포 환경 검증, 연속 위치 추적/턴바이턴 안내.

## 주소 카드 높이와 다음 이동 일정

- 최종 변경: 한국 시각 기준 오늘의 진행 중/예정 수업만 표시한다. 내일 이후와 종료 수업 목록을 제거했으며, 남은 수업이 없으면 `오늘 일정이 종료되었습니다`를 표시한다. 오늘 목록의 4개 제한도 제거했다. 날짜 경계·종료 시각·빈 목록·삭제 제외 등 테스트 5개와 운영 빌드 통과.

- 최종 반영: 다음 이동 일정 카드를 운영 빌드에 포함하고, 다음 수업 유무와 관계없이 `오늘 종료된 수업` 목록을 추가했다. 오늘 종료된 수업이 없을 때도 빈 상태를 표시한다. 주소 카드 높이는 별도 축소 작업의 72px을 유지한다.
- 완료 수업은 한국 시각의 오늘 날짜와 실제 종료 시각으로 판단하며 삭제·진행 중·어제 수업은 제외한다. 테스트 6개와 운영 빌드 통과.

- 출발·도착 주소 카드의 가로 너비를 유지하고 높이를 90px에서 108px로 늘렸다.
- 하단에 시간표와 동일한 ScheduleContext의 수업을 한국 시각 기준으로 정렬해 다음 이동 일정 최대 4개를 표시한다. 수업 시각·강의실·출발지→건물 표시 및 도착지 설정을 연결했다.
- 진행/종료된 수업·삭제한 수업은 제외한다. 온라인 수업은 이동 없음, 매칭되지 않는 강의실은 위치 확인 필요로 표시한다. 시간표 데이터 변경·30초 경과·창 포커스 시 목록이 갱신된다.
- 변경 파일: `Front/src/pages/CampusMapPreviewPage.jsx`, `Front/src/pages/CampusMapPreviewPage.css`, `Front/src/components/common/CampusNextMoves.jsx`, `Front/src/utils/campusNextClasses.js`, `Front/src/utils/campusNextClasses.test.js`, `md/folder.md`.
- 새 API 없음. 기존 ScheduleContext의 일정 API와 기존 건물 API 사용. 이동 시간을 임의로 생성하지 않는다.
- 검증: 날짜 경계·지난 수업/삭제 수업 제외·건물 매칭·온라인 수업 처리 테스트 4개와 운영 빌드 통과. 브라우저에서 주소 카드 108px(기존 90px), 기존 너비 396px 유지, 실제 다음 수업의 본부동 도착지 설정을 확인했다.

## 출발 위치 직접 지정 보완

- 출발 건물 드롭다운을 제거하고 기본 출발지를 현재 위치(예시)로 변경했다.
- `현재 위치`와 `지도에서 지정` 조작을 추가했다. 지도에서 임의의 지점을 누른 뒤 `이 위치에서 출발`로 확정하며, 취소하면 기존 출발지와 경로를 유지한다.
- SVG의 실제 화면 변환 행렬로 클릭 지점을 변환해 확대·축소 이후에도 선택 위치와 핀이 일치하도록 처리했다. 방향키 이동·Enter 확정·Escape 취소도 제공한다.
- 직접 지정한 출발 지점을 경로 시작점과 요약에 반영하고 출발·도착 교환 시 지정 지점을 보존한다.
- 프론트 UI 범위로 유지한다. `현재 위치`는 계속 예시이며 실제 GPS와 카카오 지도는 연결하지 않았다.
- 변경 파일: `Front/src/pages/CampusMapPreviewPage.jsx`, `Front/src/pages/CampusMapPreviewPage.css`.
- 사용 API: 추가 없음.
- 페이지 제목 아래 안내 문구를 제거했다.
- 브라우저에서 건물 밖 임의 지점 지정, 확정 후 경로 표시, 취소 후 기존 지점 유지 동작을 확인했다.
- 직접 지정 위치의 출발·도착 교환 및 키보드 방향키·Enter 확정을 확인했다. 1.2배 확대 시 화면 클릭 좌표 `(280, 375)`와 핀 중심 좌표가 일치했으며 320px 화면의 가로 넘침과 콘솔 오류가 없었다.

## 도착 위치 직접 지정 보완

- 도착 건물 드롭다운도 지도 지정 버튼으로 변경했다. 상단 도착 입력란 또는 `도착 위치 지정` 버튼으로 임의 지점을 선택하고 `이 위치로 도착`으로 확정한다.
- 출발·도착에 같은 위치 선택 처리를 적용하고 안내 문구·임시 핀·확정·취소·키보드 조작을 선택 대상에 맞춰 제공한다. 두 지점을 모두 직접 지정해도 독립적으로 보존하며 경로 시작·끝과 요약에 반영한다.
- 위치 지정 중에는 교환 버튼을 비활성화한다. 선택 취소는 기존 지점과 경로를 유지한다.
- 변경 파일: `Front/src/pages/CampusMapPreviewPage.jsx`, `Front/src/pages/CampusMapPreviewPage.css`.
- 사용 API: 추가 없음. 지도·위치·경로는 기존과 동일하게 프론트 화면 검토용 예시다.
- 브라우저에서 건물 밖 도착 지점 지정, 확정·취소, 출발·도착 직접 지정 후 좌표 교환, 요약 반영 및 320px 가로 넘침 없음을 확인했다.
