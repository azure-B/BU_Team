- 일시: 2026-11-05
- 영역: Front

## 변경 요약

- 안드로이드 영상의 16.000초 부근에서 이전 화면 복제본이 나타나기 전 새 테마의 빈 화면이 노출되는 현상 확인.
- 불투명 마스크를 적용한 복제본을 먼저 마운트하고 두 번의 requestAnimationFrame 후 실제 모드와 파동을 시작하도록 변경. 준비 중에도 중복 전환 방지 및 닫기·리사이즈 시 취소 처리 유지.
- 언어 트레이닝의 텍스트 입력·전송 활성화. 전송한 문장은 트레이닝 전용 대화에 저장하며 마지막 메시지로 스크롤. 비서 API 응답과 대화는 계속 분리.
- 음성 녹음·언어 AI 응답은 미연결. 임의의 자동 답변을 생성하지 않음.
