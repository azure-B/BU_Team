# Front 작업 내역

## 미커밋 타이포그래피 변경 분리 커밋 및 배포

- 사용자 지시에 따라 이번 작업은 프로젝트 자동화 규칙으로 진행한다. 변경 확인, 원격 동기화, 검증, 작업별 커밋 후 `origin/main`에 push한다.
- 기존 미커밋 변경은 공통 타이포그래피 토큰·앱 화면 스타일, 로그인 화면 스타일, 작업 기록·최신 빌드 산출물로 나누어 커밋한다.
- 원격 동기화: `git pull origin main` 결과 이미 최신 상태이며 충돌 없음.
- 변경 파일: `Front/src/styles/global.css`, `Front/src/components/common/Button/Button.css`, `Front/src/components/dashboard/DashboardSections.css`, `Front/src/components/layout/{Header/Header.css,Footer/Footer.css}`, `Front/src/components/mypage/MyPageSections.css`, `Front/src/components/setting/SettingSections.css`, `Front/src/pages/{HomePage.css,MyPage.css,SettingPage.css,SchedulePage.css,LoginPage.jsx,LoginPage.css}`, `Front/publish/index.html`, `Front/publish/assets/`, `md/folder.md`, `md/jobs/front/2026-10-07.md`.
- 사용 API: 없음 (기존 클라이언트 타이포그래피 변경 배포).
- 일정 테스트: `npm run test:schedule` 9건 통과.
- 최종 빌드: `npm run build -- --emptyOutDir false` 성공. CSS `index-ByQWjI35.css`, JS `index-CRyrEL66.js`가 생성되었으며 500kB 초과 번들 경고는 남아 있다.
- 기존 산출물을 삭제하지 않고 빌드했다. 작업 시작 전에 이미 삭제 상태였던 두 이전 빌드 파일은 해당 상태를 커밋에 반영한다.
- GitHub 공개 API의 기존 커밋 상태·체크·배포 기록에서는 자동 배포 결과를 확인할 수 없었다. 실제 호스팅 배포 완료 여부는 Git push 성공 여부와 별도로 확인해야 한다.
