# Front 작업 내역

## 미커밋 타이포그래피 변경 분리 커밋 및 배포

- 사용자 지시에 따라 이번 작업은 프로젝트 자동화 규칙으로 진행한다. 변경 확인, 원격 동기화, 검증, 작업별 커밋 후 `origin/main`에 push한다.
- 기존 미커밋 변경은 공통 타이포그래피 토큰·앱 화면 스타일, 로그인 화면 스타일, 작업 기록·최신 빌드 산출물로 나누어 커밋한다.
- 원격 동기화: `git pull origin main` 결과 이미 최신 상태이며 충돌 없음.
- 변경 파일: `Front/src/styles/global.css`, `Front/src/components/common/Button/Button.css`, `Front/src/components/dashboard/DashboardSections.css`, `Front/src/components/layout/{Header/Header.css,Footer/Footer.css}`, `Front/src/components/mypage/MyPageSections.css`, `Front/src/components/setting/SettingSections.css`, `Front/src/pages/{HomePage.css,MyPage.css,SettingPage.css,SchedulePage.css,LoginPage.jsx,LoginPage.css}`, `Front/publish/index.html`, `Front/publish/assets/`, `md/folder.md`, `md/jobs/front/2026-10-07.md`.
- 사용 API: 없음 (기존 클라이언트 타이포그래피 변경 배포).
- 일정 테스트: `npm run test:schedule` 9건 통과.
- 최종 빌드: `npm run build -- --emptyOutDir false` 성공. CSS `index-ByQWjI35.css`, JS `index-CRyrEL66.js`가 생성되었으며 500kB 초과 번들 경고는 남아 있다.
- 기존 산출물을 삭제하지 않고 빌드했다. 작업 시작 전에 이미 삭제 상태였던 두 이전 빌드 파일은 해당 상태를 커밋에 반영한다.
- GitHub 공개 API의 기존 커밋 상태·체크·배포 기록에서는 자동 배포 결과를 확인할 수 없었다. 실제 호스팅 배포 완료 여부는 Git push 성공 여부와 별도로 확인해야 한다.

## 17:17 — 합의된 범위 밖의 프론트 기능 제거

- 사용자의 명시적 요청에 따라 별도 추가 기능을 제거했다. 회원 탈퇴는 유지한다.
- 마이페이지에서 학점·GPA·졸업요건·인증포인트·성적 관리 카드와 AI 동행·질문 건수 통계를 제거했다. 요약 노트는 유지하고 자료·요약 보관함 항목으로 연결할 mock UI를 남겼다.
- 설정에서 자동 STT, TTS, 답변 상세도, 실시간 AI 브리핑 옵션, 셔틀 도착 알림, 엘리베이터 혼잡 안내, 화면 모드·캐시 정리·앱 버전·약관/라이선스 등 부가 앱 정보, 계정 전환을 제거했다. 수업·과제 및 공지의 기본 알림, 프로필 정보, 일반 이동 경로 안내, 로그아웃과 회원 탈퇴를 유지했다.
- 홈의 엘리베이터 혼잡 문구는 일반 이동 시간 안내로 바꿨다. 주간 시간표의 학점 표기와 관련 mock 데이터 필드를 제거했다.
- 제거된 컴포넌트의 import/export, 상태·타이머 및 관련 스타일도 정리했다. 기존 mock UI 방식과 페이지 라우트는 유지하며 프로필/설정 통합 및 백엔드 연동은 이번 변경에 포함하지 않는다.
- 변경 파일: `Front/src/components/mypage/{MyPageSections.jsx,MyPageSections.css}`, `Front/src/components/setting/{SettingSections.jsx,SettingSections.css}`, `Front/src/components/dashboard/DashboardSections.jsx`, `Front/src/components/schedule/scheduleModel.js`, `Front/src/pages/{MyPage.jsx,SettingPage.jsx,ScheduleWeeklyPage.jsx,SchedulePage.css}`, `Front/publish/index.html`, `Front/publish/assets/`, `md/jobs/front/2026-10-08.md`.

- 검증: 일정 모델 테스트 9개 통과. `npm run build -- --emptyOutDir false` 성공. Playwright + Chrome으로 320px/390px/1440px에서 삭제 항목 부재, 가로 넘침 없음, 회원 탈퇴·알림·요약 보관함·일정 추가 및 AI비서 유지, 런타임 오류 없음 확인. 모바일 스크린샷 검토 완료. 500kB 초과 번들 경고는 남아 있다.
