# 일정 모달의 수업 추가 모드

- 일시: 2026-10-11
- 영역: Front

## 변경 요약

- 기존 새 일정 추가 모달에 일정 추가/수업 추가 선택 UI를 넣었다. 각 모드의 입력 초안을 따로 유지하며 모드에 맞게 제목, 입력 필드, 저장 버튼을 변경한다.
- 수업 제목, 월~금 단일 요일, 시작 시간, 전공/교양을 입력한다. 종료 시간 필드가 없는 MVP이므로 수업 길이는 1시간이며 폼에 안내한다. 하루 안에 끝나도록 시작 시간은 00:00~23:00으로 제한한다.
- 같은 요일의 기존 수업과 시간이 겹치면 안내하여 시간표 블록이 가려지는 것을 방지한다. 수업 블록과 겹치는 AI 추천 블록은 그리드에서 숨긴다(상세 일정에는 유지).
- 수업은 삭제할 때까지 매주 반복한다. 기존 예시 수업의 학기 날짜 제한과 종강일 문구도 제거했다. 추가 수업을 저장하면 해당 요일을 선택하고 주간 그리드·월간 달력·날짜별 상세에 즉시 반영한다.
- 전공은 파란색, 교양은 초록색으로 구분한다. 시작 시각의 분을 정확히 표시하고 09~18시 밖의 수업이 있으면 그리드 시간 범위를 확장한다.
- 날짜별 상세에 수업 삭제 버튼을 추가했다. 추가 수업과 기존 예시 수업의 삭제 상태를 로컬 저장하며, 이후 모든 주에서 제외한다.
- 기존 저장 키를 유지하고 수업·삭제 목록 필드가 없는 이전 저장값에는 빈 목록을 적용해 기존 일정과 선택 날짜를 보존한다.

## 변경 파일

- `Front/src/pages/SchedulePage.jsx` — 모드 분기·폼·추가 및 삭제 처리
- `Front/src/pages/SchedulePage.css` — 모드 선택·입력 안내·카테고리·그리드 스타일
- `Front/src/pages/ScheduleWeeklyPage.jsx` — 반복 수업 그리드와 가변 시간 범위
- `Front/src/pages/ScheduleMonthlyPage.jsx` — 반복 수업의 월간 표시
- `Front/src/components/schedule/ScheduleDetails.jsx` — 수업 종류 및 삭제 버튼
- `Front/src/components/schedule/scheduleModel.js` — 수업 모델·영구 반복·저장값 호환·삭제
- `Front/src/components/schedule/scheduleModel.test.js` — 반복 정책·저장 호환·삭제·입력 검증
- `Front/publish/index.html`, `Front/publish/assets/` — 배포 빌드
- `md/folder.md`, 본 작업 기록

## 사용 API

- 없음. 기존 프론트 mock/로컬 저장 방식으로 구현했으며 백엔드 연동을 추가하지 않았다.

## 검증

- 일정 모델 테스트 12개 통과. 이전 저장값의 보존, 새 수업 입력 검증, 분 단위 시간, 연도 경계의 반복, 삭제 후 복원 확인.
- Chrome/Playwright 320·390·1440px에서 모드 전환 및 초안 보존, 필드 구성, 전공·교양 색상, 즉시 그리드 반영, 시간 중복 안내, 이른 시간의 그리드 확장, 주간·월간 및 새로고침 복원, 2027년 반복, 삭제 지속, 기존 일정 저장 확인. 가로 넘침과 런타임 오류 없음. 모바일 스크린샷 검토.
- 프로덕션 빌드 성공. 기존 500kB 번들 경고는 유지한다.
