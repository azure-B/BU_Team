# Front 작업 내역

## 14:30 — AI비서 버튼과 기존 모달 사이의 변형 모션 적용

- 하단에서 올라오던 모달을 AI비서 버튼의 원형 표면이 기존 모달로 확장되는 모션으로 변경했다. 닫을 때는 같은 표면이 버튼 위치로 돌아온다.
- 기존 색상, 질문창, 추천 질문, 전송 동작을 유지했다. 참조 프롬프트의 다른 UI 상태, 음악, 영상은 추가하지 않았다.
- 크기·위치·모서리를 감쇠 스프링으로 변경하고, 아이콘과 모달 내용은 별도의 짧은 블러·불투명도 타이밍으로 교체한다. 텍스트 자체를 확대하지 않는다.
- 화면 크기와 모바일 가상 키보드에 맞춰 위치를 재측정하며, 모션 줄이기 설정에서는 즉시 전환한다. Escape 닫기, 포커스 복귀 및 모달 안의 Tab 이동을 지원한다.
- 변경 파일: `Front/src/components/layout/Footer/Footer.jsx`, `Front/src/components/layout/Footer/Footer.css`, `Front/publish/index.html`, `Front/publish/assets/index-BAyK-4TJ.css`, `Front/publish/assets/index-CDJXxWQH.js`, `md/jobs/front/2026-10-07.md`, `md/folder.md`
- 사용 API: 없음 (기존 UI 모션 수정)
- 검증: Playwright + Chrome으로 390×844 및 1440×1000 화면에서 동일 DOM 표면의 확장·복귀, 버튼 위치 일치, 추천 질문 입력, Escape·닫기 버튼, 포커스 복귀, 빠른 방향 전환, 모션 줄이기 설정, 브라우저 런타임 오류 없음 확인.
- 빌드: `npm run build -- --emptyOutDir false` 성공. 기존 산출물은 유지하고, 이번 작업의 중간 JS 산출물만 휴지통으로 이동했다. 500kB 초과 번들 경고는 남아 있다.
