# AI 비서 모달 언어 트레이닝 모드 전환

- 일시: 2026-11-05
- 영역: Front

## 변경 요약

- 기존 모달의 추천 질문 칩과 같은 줄 우측에 34px 사각형 아이콘만 있는 모드 전환 버튼 추가. 모드 이름은 표시하지 않으며 접근성 이름과 툴팁으로 전환 대상을 안내.
- 추천 질문 스크롤 영역의 할당 폭을 줄여 모드 버튼 공간을 확보. 모드 버튼은 스크롤 영역 밖에 고정.
- 비서 모드에서는 보라색 뇌 아이콘의 언어 트레이닝 버튼, 트레이닝 모드에서는 기존 네이비 다이아 아이콘의 백석AI 비서 버튼 표시.
- 모드별 상단 제목·설명·아이콘 변경. 트레이닝 모드에는 보라색 그라데이션 외곽선과 매우 연한 보라색 배경 적용.
- 버튼 중심에서 원형으로 새 화면을 드러내며 파동이 퍼지는 780ms 전환을 양방향 적용. 이전 화면 복제본은 접근성 트리와 입력 대상에서 제외하며 전환 종료·모달 닫기·크기 변경·언마운트 시 정리.
- 동작 줄이기 설정에서는 애니메이션 생략. 기존 펼치기·접기 및 입력값·대화 상태 유지.
- 참고 구도를 기존 폰트·크기에 맞춘 오늘의 문장, 1분 타이머 대기 표시, 파형, 마이크 버튼으로 구현. 피드백 예시 버튼은 실제 녹음 없이 연습 문장과 교정 예시를 트레이닝 채팅 말풍선으로 추가.
- 비서와 언어 트레이닝은 대화 목록·입력 상태·로컬 저장 키를 분리. 삭제는 현재 모드에만 적용. 기존 합쳐진 저장 데이터에 연습 예시가 있으면 트레이닝 내역으로 분리하여 보존.
- 비서 API 요청이 진행 중 모드를 바꿔도 응답은 비서 대화에만 추가. 언어 모드에는 비서 로딩·AI 연결 배지를 표시하지 않음.
- 트레이닝 모드 진입 파동이 끝나면 접힌 모달을 펼쳐 연습 UI 표시. 실제 녹음·평가 API는 연결하지 않았으며 일반 트레이닝 입력·음성·전송·추천 질문은 비활성화.
- 모달 손잡이를 누를 때 기본 → 기존 최대 600px → 상하 여백이 같은 최대 크기 → 기본 순으로 전환. 메시지 전송과 트레이닝 진입 시 이미 최대 크기라면 해당 크기를 유지.
- 언어 트레이닝에서 추천 질문 제목과 칩을 숨기고 모드 전환 아이콘만 우측에 유지. 예시 문장을 `I am still hungry.`로 변경하고 피드백 예시도 문법에 맞게 갱신.

## 사용 API

- 신규 API 없음. 모드 전환은 로컬 상태만 변경.
- 기존 `POST /api/chat`은 비서 모드에서만 기존 방식으로 사용.

## 검증

- 모달 상단 휴지통 버튼을 오른쪽으로 밀어 닫기 버튼과 10px 간격(중심 간 42px)으로 배치.

- 언어 트레이닝 하단에 언어 변경·다음 문제 및 영어/일본어/중국어/독일어 선택 버튼 추가. 언어별 예시 두 문장을 순환.
- 두 모드의 하단 제목 줄 24px, 버튼 줄 36px로 통일하여 같은 모달 크기에서 채팅 입력창의 높이와 위치 유지.

- Vite 프로덕션 빌드 성공. 기존 publish 파일을 삭제하지 않도록 별도 산출 경로와 `--emptyOutDir false` 사용.
- 브라우저에서 트레이닝 모드의 제목·설명·보라색 테마, 비서 모드 복귀, 왕복 전환 후 입력값 유지 확인.
- 브라우저에서 트레이닝 피드백이 비서 내역에 노출되지 않는 것, 비서 입력값이 트레이닝 입력에 섞이지 않고 복귀 시 복원되는 것 확인.
- 새로고침 후 트레이닝 기록 복구 및 접힌 모달에서 트레이닝 진입 후 자동 펼치기 확인.
