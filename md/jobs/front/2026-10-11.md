## AI비서 접힘 상태에서 채팅 말풍선 노출 방지

- 메시지를 보낸 뒤 모달을 접으면 채팅 영역이 레이아웃에 남아 말풍선 일부가 보이는 현상을 재현했다.
- 접힌 상태에서는 대화 영역을 `visibility: hidden`으로 감추고, 펼친 상태에서 다시 표시해 채팅 내용이 입력창 주변으로 삐져나오지 않게 했다. 기존 영역 크기와 주변 컨텐츠 위치는 유지한다.
- 변경 파일: `Front/src/components/layout/Footer/Footer.css`, `Front/publish/index.html`, `Front/publish/assets/`, `md/jobs/front/2026-10-11.md`
- 사용 API: 없음
- 검증: `npm run build -- --emptyOutDir false` 성공. 로컬과 배포 화면에서 AI비서 열기 → 메시지 전송 → 접기 시 말풍선이 사라지고, 다시 펼치면 대화 내용이 복원되는 것을 확인했다. 기존 500kB 초과 번들 경고는 남아 있다.
