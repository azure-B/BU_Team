## 구현된 API 엔드포인트

### Campus (캠퍼스 데이터)

| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/api/v1/campus/buildings` | 전체 건물 목록 조회 |
| GET | `/api/v1/campus/classrooms?buildingId=` | 강의실 조회 (건물 필터) |
| GET | `/api/v1/campus/facilities?type=` | 시설 조회 (카페, 편의점, 학식 등 타입 필터) |
| GET | `/api/v1/campus/cafeteria?date=YYYY-MM-DD` | 날짜별 학식 메뉴 조회 |
| POST | `/api/v1/campus/route/lateness` | 동선 계산 및 지각 위험도 반환 (조장님 모듈 연동) |

### 지각 위험도 API 요청 형식
```json
POST /api/v1/campus/route/lateness
{
  "currentBuildingId": "건물UUID",
  "nextClassBuildingId": "건물UUID",
  "nextClassStartAt": "2026-10-04T11:00:00Z"
}
```

### 지각 위험도 API 응답 예시
```json
{
  "success": true,
  "data": {
    "walkingMinutes": 3,
    "minutesLeft": 4,
    "latenessRisk": 50,
    "latenessLevel": "WARNING",
    "recommendedFacilities": [...],
    "message": "서두르는 것이 좋습니다."
  }
}
```
