# [2026.10.25] 카카오맵 키워드 검색으로 Building 좌표 갱신

## 작업
- `KAKAO_REST_API_KEY`로 `dapi.kakao.com/v2/local/search/keyword.json` 검색
- 캠퍼스 10개 Building의 `x`(위도)·`y`(경도)를 카카오 place 좌표로 upsert
- 학생회관은 카카오상 **백석대학교 학생복지관** 좌표 사용 (타 대학 학생회관 오매칭 방지)

## 재실행
```bash
cd Back && node scripts/sync-building-coords-kakao.mjs
```

## 산출물

| `Back/scripts/sync-building-coords-kakao.mjs` | 동기화 스크립트 |
