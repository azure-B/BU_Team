## 구현된 API 엔드포인트

### Auth (sample2.html 연동 — 학번 기반)
| Method | Endpoint | 설명 |
|--------|----------|------|
| POST | `/api/v1/auth/register` | 회원가입 (studentId + password) |
| POST | `/api/v1/auth/login` | 로그인 → JWT 발급 |
| GET | `/api/v1/auth/me` | 내 정보 조회 (Bearer 토큰 필요) |

### Schedule (일정)
| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/api/v1/schedules` | 일정 목록 조회 (from/to 날짜 필터) |
| POST | `/api/v1/schedules` | 일정 추가 |
| PATCH | `/api/v1/schedules/:id` | 일정 수정 |
| DELETE | `/api/v1/schedules/:id` | 일정 삭제 |

### Task (과제/할 일)
| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/api/v1/tasks` | 전체 과제 조회 |
| POST | `/api/v1/tasks` | 과제 추가 |
| PATCH | `/api/v1/tasks/:id` | 과제 수정 |
| DELETE | `/api/v1/tasks/:id` | 과제 삭제 |
| GET | `/api/v1/tasks/today/recommendations` | 우선순위 Top 3 (조장님 모듈 연동) |

### Dashboard (홈 통합)
| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/api/v1/dashboard/today` | 오늘의 수업 + 과제 + 유저 정보 통합 반환 |
